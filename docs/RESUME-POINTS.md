## Common Interview Questions - Quick Answers

**Q: Why Selenium Grid instead of cloud providers?**
A: Cost control ($0 vs. $24k-40k annually), data security (no external data transfer), and full infrastructure control while maintaining scalability.

**Q: How did you achieve 75% time reduction?**
A: Three-layer parallelism - browser-level (Chrome || Firefox), scenario-level (3 threads per browser), and infrastructure-level (2 Grid nodes for scaling).

**Q: Explain ThreadLocal implementation.**
A: ThreadLocal provides isolated WebDriver storage per thread, preventing cross-thread interference in parallel execution. Each thread gets its own WebDriver instance, ensuring test isolation.

**Q: How do you handle flaky tests?**
A: Multi-layer strategy - retry logic for infrastructure issues (5 attempts), explicit waits for AJAX content, defensive element locators, and collaboration with dev team on test mode flags.

**Q: What's your mentorship approach?**
A: Graduated autonomy - start with pair programming (I do/you watch), move to guided tasks (we do together), then independent work with code reviews (you do/I review), finally autonomous contribution.
